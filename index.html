三条能力线

  • 智能调温：2R2C 灰盒热模型 + 占空预测 + 多住户 minimax 折中 + 分时电价
  • 习惯记忆：记忆存数据库而非模型权重 —— 可解释、可更正、可删除（被遗忘权）
  • 灾难引导：路线来自确定性图算法，小模型只负责措辞； 火源房间转为就地避险；模型不可用时退化到预置广播

安全设计（核心，不是附属）

模型只出"意图"，绝不直接控制设备。每条指令都要过七道闸门：

  • 闸1 Schema · 闸2 权限 · 闸3 场景互锁（应急状态拒绝一切舒适性调节）
  • 闸4 物理边界 · 闸5 变更率限幅（防抖）· 闸6 设备保护 · 闸7 置信度

另外：阈值写在配置表而不是提示词里；模型没有应急触发权限； 审计链式哈希 + 条数封印，改字段或删记录都能被发现；校验器异常时 fail-closed。

最值得记的一条结论

格式靠约束解码，语义靠规则 + 微调。 JSON Schema 约束把格式合法率推到 97.3%，但纯模型的语义命中率只有 17.3% —— 这两件事必须分开投入。生产路径是"规则有定论就不调模型"，模型只用于长尾救援。
